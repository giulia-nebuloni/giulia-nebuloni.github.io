Sito Web & Portfolio Personale Bilingue

2026
Sviluppo assistito da AI con Google Antigravity • Static Web / GitHub Pages

Questo portfolio è stato progettato e implementato come progetto dimostrativo di collaborazione uomo-macchina. Il sito presenta la documentazione professionale, il percorso assicurativo, le esperienze a Praga e il volontariato con un'architettura statica, pulita, bilingue e priva di dipendenze esterne.

Obiettivo Creare un portfolio bilingue (IT/EN) veloce, accessibile, manutenibile e ospitato a costo zero su GitHub Pages.
Architettura & Tecnologie HTML5 semantico, CSS3 modulare e responsive, JavaScript nativo (vanilla JS) per la localizzazione client-side istantanea, Git per il versionamento del codice.
Ambiente di Sviluppo Google Antigravity (ambiente di sviluppo e coordinamento agentico).
Modello AI Utilizzato nello Sviluppo Gemini 3.8 Flash (impiegato per l'analisi documentale del CV, la strutturazione dei contenuti bilingui, la redazione del codice frontend e la verifica di coerenza).
Modelli AI in Produzione Nessuno: Il sito è un'applicazione web statica pura in produzione. L'intelligenza artificiale è stata impiegata esclusivamente durante la fase di progettazione, redazione dei contenuti e programmazione del codice sorgente.

Istruzioni per l'esecuzione e ricostruzione locale

Non sono necessari package manager o build step complicati. Per testare o eseguire il progetto in locale:

# 1. Clona la repository o accedi alla cartella
git clone https://github.com/giulianebuloni/giulia-nebuloni.github.io.git
cd giulia-nebuloni.github.io

# 2. Apri direttamente index.html con un qualsiasi browser
open index.html
